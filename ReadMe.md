# Laundry Service Website

## 📌 Project Description

This project is a responsive Laundry Service landing page built using HTML and CSS. It provides information about laundry services and includes a navigation bar, service description, call-to-action button, and laundry image.

The main objective of this project is to make the website responsive across desktop, tablet, and mobile devices using CSS media queries.

## ✨ Features

- Responsive navigation bar
- Laundry service hero section
- Service description and heading
- Book a Service button
- Laundry service image
- Tablet and mobile responsive layouts
- CSS Flexbox for layout management
- CSS media queries for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## 📱 Responsive Breakpoints

| Device | Screen Width |
|---|---|
| Mobile | Up to 767px |
| Tablet | 768px–1023px |
| Desktop | 1024px and above |

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Keep `task.html` and `task.css` in the same folder.
3. Open `task.html` in your web browser.
4. Resize the browser window to test the responsive layout.

## 🖼️ Image

The laundry image is loaded using an external image URL. An internet connection is required to display it.
